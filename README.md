# 🎨 個人靈感塗鴉牆 (Padlet Personal Clone + Google Sheet 資料庫)

這是一個以 **Google Sheet 作為雲端資料庫**、**Google Drive 作為圖片儲存空間** 的個人塗鴉牆（`padlet_personal` 範本）。無須架設傳統後端伺服器，直接雙擊打開 `index.html` 或部署至 GitHub Pages 即可使用！

---

## ✨ 功能亮點

1. **📝 張貼留言與便利貼**：
   - 自訂作者暱稱、標題、多行留言內容、5 大分類標籤與 6 種便利貼顏色。
   - 支援**置頂貼文 (`📌`)**、**按愛心 (`❤️`)** 以及**每張卡片下方的留言回覆串 (`💬`)**。
   - 雙擊塗鴉牆空白處或點擊右下角「`＋`」按鈕即可快速發文。
2. **🖼️ 多元圖片上傳**：
   - 支援**點擊選擇照片**、**拖曳圖片上傳**、**直接按 `Ctrl + V` 貼上剪貼簿截圖**，或直接輸入外部圖片網址。
   - 前端自動進行 Canvas 智慧壓縮，透過 Google Apps Script 自動存入您的 **Google Drive (`Padlet_塗鴉牆圖片` 資料夾)** 並將圖片連結寫入 Google Sheet。
   - 點擊卡片上的圖片可開啟高畫質燈箱放大檢視。
3. **🔗 附加外部連結卡片**：
   - 每則貼文皆可附上外部網址與自訂連結名稱，自動產生可點擊的連結卡片。
4. **🎨 4 種塗鴉牆背景與雙排版切換**：
   - 內建「經典軟木塞」、「星空深色」、「晨曦漸層」、「極簡方格」4 種背景，以及「瀑布流網格 / 單欄動態流」切換。
   - 點擊上方主標題與副標題可直接修改並自動儲存。

## 🚀 3 分鐘串接 Google Sheet 資料庫教學

### 步驟 1：建立 Google 試算表與 Apps Script
1. 前往 [sheets.new](https://sheets.new) 建立一個全新的 Google 試算表。
2. 點選上方選單 **「擴充功能」 &rarr; 「Apps Script」**。
3. 複製本資料夾中 [`google-apps-script.gs`](./google-apps-script.gs) 的所有程式碼，貼上並取代 Apps Script 編輯器中原本的 `Code.gs` 內容，按 `Ctrl + S` 儲存。

### 步驟 2：部署為網頁應用程式 (Web App)
1. 點選 Apps Script 右上角的 **「部署」 &rarr; 「新增部署作業」**。
2. 點擊左上角齒輪「選取類型」，選擇 **「網頁應用程式 (Web App)」**。
3. 設定如下：
   - **執行身分 (Execute as)**：選擇 **「我 (Me)」**
   - **誰可以存取 (Who has access)**：選擇 **「所有人 (Anyone)」** *(重要！這樣前端網頁才能跨域讀寫)*
4. 點選 **「部署」**，並在跳出的 Google 授權視窗中點選「核准存取權」（若出現「Google 尚未驗證這個應用程式」，點選左下角「進階」&rarr;「前往... (不安全)」&rarr;「允許」）。
5. 複製產生的 **「網頁應用程式網址 (Web App URL)」**（結尾為 `/exec`）。

### 步驟 3：在塗鴉牆前端綁定網址
1. 用瀏覽器打開 [`index.html`](./index.html)。
2. 點擊右上角 **「⚙️ Google Sheet 設定」**。
3. 將剛剛複製的 Web App URL 貼入輸入框，可先點擊 **「🔌 測試連線」** 確認連線成功，接著點擊 **「💾 儲存並連線」** 即完成！
4. 系統會自動在您的試算表建立 `Posts` 工作表與欄位標題，並在您的 Google Drive 自動建立 `Padlet_塗鴉牆圖片` 資料夾存放上傳的圖片。

## 🛡️ 後臺管理系統 (`admin.html`)

點擊塗鴉牆右上角的 **「🛡️ 後臺管理」** 按鈕（或直接前往 `/admin.html`），輸入管理員密碼（**預設密碼：`1234`**，可於後臺修改）即可進入後臺控制台：

1. **📋 貼文審核與批次管理**：
   - 支援「**✅ 已公開**」、「**⏳ 待審核**」、「**👁️‍🗨️ 已隱藏**」三種狀態篩選。
   - 支援完整編輯任意貼文（修改標題、作者、分類、顏色、圖片、外部連結、愛心數、置頂狀態）。
   - 支援多選**批次審核通過**、**批次隱藏**、**批次永久刪除**。
2. **💬 留言互動管理**：
   - 集中檢視所有卡片底下的訪客留言，可一鍵刪除不當留言。
3. **📊 數據統計分析**：
   - 即時統計總貼文數、待審核數、累計愛心與留言數，並呈現各分類佔比、熱門貼文排行、活躍作者排行與便利貼顏色分佈。
4. **⚙️ 牆面與權限設定**：
   - 可從後臺設定「**頂部置頂公告橫幅**」、「**是否開放訪客發文**」、「**是否啟用先審核後公開機制**」、「**是否開放留言**」，並同步儲存至 Google Sheet 的 `Settings` 工作表。
5. **📥 匯出 Excel CSV 報表與 JSON 備份**：
   - 一鍵匯出 UTF-8 CSV 試算表報表（可直接用 Excel 開啟評分或歸檔）以及 JSON 完整備份還原。
